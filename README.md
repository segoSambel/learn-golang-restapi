## Overview

`learn-golang-restapi` is a lightweight, production-ready Go RESTful API designed for secure user registration and management. It leverages standard clean architecture practices by decoupling request validation, service logic, and type-safe database queries. The service serves as a backend API template demonstrating structured SQL operations code-generated by SQLC.

---

## Features

- **Type-Safe Database Operations** — Employs `sqlc` to generate performant and type-safe Go database code directly from raw SQL files.
- **Connection Pooling** — Uses `pgx/v5` connection pools for robust, concurrent PostgreSQL connectivity.
- **Schema Migrations** — Up and down SQL migrations under `migrations/`, applied with the `golang-migrate` CLI.
- **JWT Authentication** — Issues HS256 access tokens on login via `golang-jwt` and protects routes with a bearer-token middleware.
- **Secure Password Hashing** — Encrypts passwords using `bcrypt` (under `golang.org/x/crypto`) prior to database storage.
- **Strict Request Validation** — Integrates `go-playground/validator/v10` to enforce request schema validation constraints (e.g. minimum password lengths, email structure).
- **Structured Request Logging** — Logs every request as JSON through `go-chi/httplog`, including the underlying error on 5xx responses.
- **Graceful Server Shutdown** — Implements listener signal capturing (`os.Interrupt`, `syscall.SIGTERM`) with a configurable timeout buffer.

## Architecture

This project is structured as a single-process application with a clean layered architecture, allowing concerns to be separated cleanly:

```
[ HTTP Request ] ──► [ Chi Router (server.go) ] ──► [ HTTP Handlers (handler.go) ]
                                                            │
                                                            ▼ (Validate Request DTO)
                                                     [ User Service (service.go) ]
                                                            │
                                                            ▼ (Hash Passwords)
[ DB Pool (pgxpool) ] ◄── [ Generated DB Queries (sqlc) ] ◄─┘
```

| Table Name | Primary Key | Column Specs | Indices | Purpose |
|:---|:---|:---|:---|:---|

## Quick Start

### 1. Clone the repository
```bash
git clone https://github.com/segoSambel/learn-golang-restapi.git
cd learn-golang-restapi
```

### 2. Configure Environment Variables
Copy the example file and edit it. A valid `DATABASE_URL` must be set:
```bash
cp .env.example .env
```
The service reads `.env` from the directory it is started in. Variables already set in the shell take precedence over the file.

### 3. Run Database Migrations
Bootstrap the database schema with the `golang-migrate` CLI. The CLI does not read `.env`, so pass the URL directly:
```bash
migrate -path migrations -database "postgres://postgres:postgres@localhost:5432/user_db?sslmode=disable" up
```

### 4. Run the Service
Start the HTTP server:
```bash
go run cmd/api/main.go
```
The server will boot up and listen on **port 8080** (or whatever `HTTP_PORT` is set to).

## Environment Variables

All variables are loaded inside [`internal/config/config.go`](file:///home/husain/dev/personal/learn/learn-golang-restapi/internal/config/config.go) during program initialization.

### HTTP Server Configs

| Variable | Default | Description |
|:---|:---|:---|
| `HTTP_HOST` | `0.0.0.0` | Bind IP address for the HTTP listener socket. |
| `HTTP_PORT` | `8080` | Bind TCP port for incoming HTTP connections. |
| `HTTP_SHUTDOWN_TIMEOUT_SECONDS` | `10` | Wait limit for graceful cancellation of active connections during server exit. |

### Database Configs

| Variable | Default | Description |
|:---|:---|:---|
| `DATABASE_URL` | — | **Required**. Connection string URL (e.g. `postgres://user:password@host:5432/dbname?sslmode=disable`). |

### Auth Configs

| Variable | Default | Description |
|:---|:---|:---|
| `JWT_SECRET` | — | **Required**. Secret used to sign and verify access tokens. Use a long random string. |
| `JWT_TTL` | `24h` | Access token lifetime, as a Go duration (e.g. `15m`, `24h`). |

## API Documentation

### Users API — `/api/v1/users`

| Method | Path | Authority | Description |
|:---|:---|:---|:---|
| `POST` | `/api/v1/users` | Public | Registers a new user. Performs email format validation and hashes passwords with bcrypt before saving. |
| `GET` | `/api/v1/users/me` | Bearer token | Returns the authenticated user. |
| `POST` | `/api/v1/auth/login` | Public | Verifies email and password and returns an access token. |

**Request Body Structure (`POST /api/v1/users`):**
```json
{
  "email": "jane.doe@example.com",
  "password": "secret123password"
}
```
*Constraints:* `email` must be a valid email string. `password` is required with a minimum length of 8 characters.

**Success Response (`201 Created`):**
```json
{
  "id": "e0dca3f0-4663-4f9e-bead-5ee7ab0db89d",
  "email": "jane.doe@example.com",
  "created_at": "2026-08-12T10:00:00Z"
}
```

**Conflict/Duplicate Email Error (`409 Conflict`):**
```json
{
  "error": {
    "code": "EMAIL_TAKEN",
    "message": "email is already registered"
  }
}
```

**Validation/Bad Request Error (`400 Bad Request`):**
```json
{
  "error": {
    "code": "VALIDATION_ERROR",
    "message": "password is invalid (min)"
  }
}
```

**Login Response (`POST /api/v1/auth/login`, `200 OK`):**
```json
{
  "access_token": "<jwt>",
  "expires_at": "2026-08-13T10:00:00Z"
}
```
Wrong email or password returns `401` with code `INVALID_CREDENTIALS`. Send the token to protected routes as `Authorization: Bearer <jwt>`; a missing, invalid or expired token returns `401` with code `UNAUTHORIZED`.
